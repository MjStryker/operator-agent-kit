# Charters

Charters are repository-owned capability contracts managed through the [`charter`](../../skills/charter/SKILL.md) skill. Their contents are defined in [`schema.md`](../../skills/charter/references/schema.md), and their lifecycle in the skill's other references. How charters, tasks, and plans compose is in [`workflow.md`](workflow.md), Operating model.

Accepted charter reviews live under `docs/charters/reviews/`. What a review record holds and how it relates to activation are defined by [`review-charter`](../../skills/review-charter/SKILL.md) and its [`record.md`](../../skills/review-charter/references/record.md).

Ordinary work does not require a charter. Use a personal or project task when one independently verifiable objective is sufficient.
