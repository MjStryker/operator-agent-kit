# Project tasks

This directory holds shareable project task contracts created through `task define project`. What a task file contains is defined in [`schema.md`](../../skills/task/references/schema.md). Discussion bindings, listing, and archival (including the `archived/` subdirectory) are defined in the [`task`](../../skills/task/SKILL.md) skill's [`core.md`](../../skills/task/references/core.md), [`list.md`](../../skills/task/references/list.md), and [`archive.md`](../../skills/task/references/archive.md).
